# Règles Globale du Projet "Portfolio Koudous"

Ce fichier définit les contraintes absolues que l'agent doit respecter à chaque interaction dans ce projet.

## 1. Philosophie Design & UX
- **Esthétique "2030" :** Privilégier le Glassmorphism, la typographie élégante, les espaces aérés (Purposeful Brightness) et le design minimaliste moderne.
- **Scrollytelling :** Penser les parcours utilisateurs de manière verticale, fluide et sans clics excessifs. Les vidéos doivent être synchronisées au scroll.

## 2. Exigences Git & GitHub (Niveau Senior)
- **Conventional Commits :** Tous les commits générés ou suggérés DOIVENT utiliser la convention `type(scope): description`. (ex: `feat(ui): ...`, `fix(seo): ...`, `chore(deps): ...`).
- **Commits Atomiques :** Faire de petits commits ciblés.
- **Propreté de l'historique :** Favoriser le *Squash and Merge* lors des intégrations.

## 3. SEO, GEO & Performance
- **10000% SEO/GEO :** L'agent doit toujours suggérer les approches les plus optimisées pour le SEO (JSON-LD, balises meta dynamiques, Edge Computing).
- **Lighthouse 100/100 :** Tout composant vidéo ou image doit implémenter du Lazy-Loading (ex: BlurHash) et éviter les sauts de mise en page (Zero-Layout-Shift).
