- (event) Spine architecture session started via Coaching Path
- (decision) AD-1: Deployment Platform is Vercel. Binds: Infra/Deployment. Prevents: Fragmentation of Edge compute. Rule: All Edge middleware and functions must target Vercel Edge Runtime.
- (decision) AD-2: Framework is Next.js (App Router). Binds: Frontend Architecture. Prevents: Heavy client-side bundles. Rule: Default to React Server Components (SSG). Client Components must be isolated and loaded dynamically.
- (decision) AD-3: Animation Engine is GSAP + Framer Motion. Binds: UI/Animations. Prevents: Janky video scrubbing or stiff UI. Rule: GSAP is exclusively used for ScrollTrigger/Scrollytelling heavy mechanics. Framer Motion handles standard UI micro-interactions and transitions to guarantee a premium Glassmorphism feel.
- (decision) AD-4: GEO-SEO Data Injection via Edge Middleware. Binds: Routing/SEO. Prevents: Slow SSR responses and loss of SSG. Rule: All pages must be SSG. GEO-SEO metadata (Meta tags, JSON-LD) must be injected dynamically via Vercel Edge Middleware intercepting the static HTML response.
- (decision) AD-5: Media Storage on External Edge CDN. Binds: Data/Media. Prevents: Bloated Git repository and slow video buffering. Rule: Raw video files must be hosted on an external edge-enabled CDN (Vercel Blob Storage or Supabase Storage depending on free tier bandwidth limits). The Git repository and Next.js backend only store lightweight metadata (URLs, BlurHash strings, VTT chapters).
- (event) spine finalized
